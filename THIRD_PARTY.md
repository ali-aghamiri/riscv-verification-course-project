# Third-party processor core

The files in `third_party/riscv-simple-sv/` are the BSD-3-Clause licensed
RISC-V SiMPLE SV teaching core by Arthur Matos, Marcus Vinicius Lamar,
Universidade de Brasília, and Marek Materzok (University of Wrocław).
They came from the processor archive supplied with the course. The original
project is https://github.com/tilk/riscv-simple-sv and its full license is
retained in `third_party/riscv-simple-sv/LICENSE`.

The processor implementation is third-party code. The stimulus generators,
archived golden model, directed test vectors, reference checker, and
self-checking testbench are separate coursework or post-course work as
identified in the README.
